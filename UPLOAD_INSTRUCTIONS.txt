GitHub Pages fix

Upload these files to the ROOT of the Malitha123/malitha repository:
- index.html
- .nojekyll
- data/CV_Malitha_Gunawardhana.pdf

The CSS is embedded inside index.html, so the site will remain styled even if stylesheet.css is cached or not deployed.
The included stylesheet.css can stay in the repository for future editing, but the live page no longer depends on it.

After committing:
1. Open repository Settings > Pages.
2. Confirm Source is Deploy from a branch, branch main, folder /(root).
3. Open Actions and wait for the Pages deployment to finish successfully.
4. Hard refresh the website with Ctrl+F5.
